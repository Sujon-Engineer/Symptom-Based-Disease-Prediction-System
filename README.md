# Symptom-Based-Disease-Prediction-System
## Project Description
This project predicts the **health outcome** of a patient based on their **symptoms and profile data**. Machine learning models like **Decision Trees** and **Random Forests** are used to learn patterns from historical patient data and forecast likely outcomes.

## Features Used
- Disease  
- Fever  
- Cough  
- Fatigue  
- Difficulty Breathing  
- Age  
- Gender  
- Blood Pressure  
- Cholesterol Level  

## Target Variable
- **Outcome Variable** – Indicates the patient’s health outcome (e.g., Recovered / Not Recovered).  
- Encoded numerically for model training.

## Technologies Used
- Python 3.x  
- Pandas  
- NumPy  
- scikit-learn  
- Matplotlib / Seaborn (optional, for visualization)
